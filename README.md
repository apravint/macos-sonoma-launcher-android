**macOS Sonoma Launcher for Android** transforms your Android phone into an Apple macOS desktop environment complete with top Menu Bar, floating magnifying Dock, and macOS Finder application drawer.

Developed by **Ayyappa Pravin** (<apravint@gmail.com>).

---

## ✨ Features

-  **macOS Top Menu Bar**: Apple menu (``), active app title, status clock, battery telemetry, and quick control panel.
- 🎨 **Floating Glassmorphic Dock**: Magnifying icon dock at screen bottom with app indicators and smooth micro-animations.
- 📁 **macOS Finder App Drawer**: Access all installed Android apps, customize desktop wallpapers, and organize layout.
- 📳 **Haptic Feedback**: Tactile vibration on icon tap and dock hover.
- 🛡️ **Universal Compatibility**: 4-Byte ZipAligned & V1/V2/V3 signed for Motorola Edge, Pixel, Samsung, and Xiaomi devices.
